La mémoire affichée est celle du processus Trame et de tous ses descendants (donc de WebView2). Aucune API ne donne la mémoire par onglet : WebView2 partage ses processus de rendu par origine.

Quand un onglet est caché

Mettre en pause après 5 minutes Ses scripts s'arrêtent, le processeur tombe presque à zéro. Jamais un onglet qui joue du son ; il reprend dès qu'on l'affiche.
Rendre sa mémoire après 20 secondes Sans se fermer ni perdre sa place. Il revient à la normale dès qu'on l'affiche.
Endormir automatiquement les onglets froids La page est déchargée ; l'onglet et sa position de lecture restent.

Combien d'onglets éveillés

Onglets réveillés en même temps, au plus Au-delà, l'onglet le moins vital est endormi.
Moins quand le PC manque de mémoire Le nombre ci-dessus devient un plafond : sous 1,5 Go libre, les onglets les plus froids s'endorment, sans jamais rien fermer.

Protection anti-pistage

Adresses

Nettoyer les adresses Retire les paramètres de pistage (utm, fbclid, campagnes Amazon…) avant d'ouvrir une page.
Sauf les identifiants d'affiliation Le « tag= » d'Amazon et ses équivalents rémunèrent le créateur qui a partagé le lien. Sans effet quand le nettoyage est coupé.

Ce que Trame retient

Garder le texte des pages lues Une page restée affichée 8 secondes est gardée sur ce PC (jamais envoyée ailleurs). Tapez « ? » suivi de quelques mots dans la barre pour la retrouver. Les pages avec un champ de mot de passe ne sont jamais gardées.
Sites jamais gardés Aucun. Depuis une page : bouton ⋯ → « Ne jamais garder ce site ».

Comment ça marche, et les limites

Les extensions Chrome sont de vraies extensions (manifeste v2/v3), chargées par le moteur de Chromium via AddBrowserExtension : scripts de contenu, page d'action, service worker, API chrome.*. Un sous-dossier = une extension, décompressée. Installer, désactiver, réactiver ou retirer prend effet tout de suite, sans redémarrer, et la page affichée est rechargée.

Trame télécharge le paquet depuis le magasin de Chrome, retire son en-tête de signature (.crx v2 ou v3), le décompresse et vérifie qu'il contient un manifeste — comme « charger une extension décompressée » dans Chrome. La signature n'est pas vérifiée : ce n'est pas une installation « validée par le magasin ».

Comme dans Chrome, le bouton puzzle de la barre liste les extensions ; l'épingle met l'icône d'une extension dans la barre d'outils, et un clic dessus ouvre sa fenêtre d'action dans le panneau de droite. « Interface » l'ouvre dans un onglet.

Deux limites : ces extensions s'appliquent aussi au rail et à la barre (ce sont des pages web), et une extension qui exige une API absente de WebView2 peut rester inerte. Une extension retirée n'est pas effacée : son dossier part dans extensions-chrome-archives\.

Les extensions Trame peuvent lire toutes les pages qu'elles ciblent : il n'y a pas encore de modèle de permissions. Désactiver prend effet au chargement suivant.
