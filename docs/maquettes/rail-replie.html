Rail replié de Trame : trois pistes

Les quatre rails sont dessinés à taille réelle, avec le contenu de ta capture : deux accès rapides, un fil de deux onglets N, un fil de deux onglets YouTube qui jouent du son, un fil vide. Les noms de fils (« Ciné », « Musique ») sont des exemples.

Des boîtes dans des boîtesChaque fil est une carte bordée, dans un rail déjà sombre : beaucoup de cadres pour peu de contenu.
Icônes trop petites16 px dans des cases de 30 px : à 64 px de large, on peut monter à 22–24 px.
Fils sans identitéUne tête de fil n'affiche qu'un chevron : rien ne dit lequel est lequel une fois replié.
États peu lisiblesLe son est une icône à côté du logo, l'onglet actif un simple contour, l'onglet endormi ne se voit pas.
