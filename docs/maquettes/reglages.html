Comment ça marche, et les limites

Ce sont de vraies extensions Chrome (manifeste v2/v3) chargées par le moteur de WebView2 : scripts de contenu, page d'action, service worker, API chrome.*. Installer, couper ou retirer prend effet tout de suite.

Trame retire l'en-tête de signature du paquet sans la vérifier : WebView2 charge des extensions locales, ce n'est pas une installation validée par le magasin.

Elles s'appliquent aussi au rail et à la barre (ce sont des pages web). Une extension retirée part dans extensions-chrome-archives\, rien n'est effacé.

Les extensions Trame peuvent lire toutes les pages qu'elles ciblent : il n'y a pas encore de modèle de permissions.
