Rail replié : accès rapides ou onglets ?

Aujourd'hui, YouTube, GitHub et Gmail (tes applications ancrées) et les onglets des groupes ont presque la même forme : une icône dans une case. Voici quatre façons de les distinguer d'un coup d'œil. Même contenu partout : 3 accès, puis tes 5 groupes. Rail à taille réelle (64 px).
